Financial Data ETL Pipeline — Humana

Built an end-to-end ETL pipeline that retrieves Humana's financial data from the SEC XBRL API, transforms and classifies financial metrics, stores the data in PostgreSQL, and generates structured Income Statement, Balance Sheet, and Cash Flow Statement datasets. The pipeline is automated with Apache Airflow and includes data validation and unit testing.
